# E-Commerce-Project---Redi
This E-Commerce Project focuses on using all the features and fundementals of React while maintaining a friendly UI using Tailwind CSS.

     

🚀 Project Features

   *  Product listing with dynamic filtering and search
   *  Shopping cart functionality
   *  esponsive design that works on all devices
   *  Product details pages
   *  State management using React's built-in hooks
   *  Clean, maintainable code structure


🛠️ Tech Stack

   * Framework: React.js
   * Styling: Tailwind CSS
   * API: DummyJSON
   * Feedback: React Spinners
   * Build Tool: Vite
